# C 統計エンジンの配線段 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** C 中核（`metabolomix/analysis/stats/`）を MCP ツールへつなぎ、対話の統計をすべてこのエンジンから出す。
v1 の対話の統計ツール（`dataset_differential`・`dataset_statistic`・`dataset_build_matrix`）を消し、`dataset_compare` を足す。

**Architecture:** ツール層は「単純な引数 → analysis-spec.v2 を組み立てる → `stats.spec_v2.run_spec_v2` などを呼ぶ →
結果をデータセットに登録・解析フォルダの `reports/stats/` に記録 → 要約だけを返す」の形にそろえる。既存の結果の利用者
（export・根拠バンドル・特徴検索・volcano 図・新しい知見の候補）は、エンジンの結果を v1 の 2 群の形に読み替える 1 つの
関数（`as_two_group`）を通して読む。pipeline（独立 worker）の v1/v2 の下流工程は D で消えるまで今のまま動かす。

**Tech Stack:** Python 3.14、numpy、scipy、FastMCP。依存は足さない。

**Spec:** `docs/superpowers/specs/2026-11-06-statistics-engine-design.md`（§12〜§15。全体は `2026-11-06-overhaul-overview-design.md` §5）。
前段の計画 `docs/superpowers/plans/2026-11-07-c-statistics-core.md`（§15 の判断表）。範囲の正準は main ツリーの `docs/task.md` §2「C の配線段」。

## 新しい公開面（ツールの最終形）

消す: `dataset_differential`、`dataset_statistic`、`dataset_build_matrix`。足す: `dataset_compare`。

### `dataset_preprocess`（引数を入れ替える）

```
dataset_preprocess(drift_mode="auto", drift_span=0.75, blank_min_ratio: float|None=3.0,
                   detection_min_rate: float|None=0.5, detection_by="group",
                   max_qc_rsd: float|None=0.30, max_d_ratio: float|None=0.5,
                   normalize="auto", collapse_replicates=True, injection_columns: list[str]|None=None,
                   group_levels: list[str]|None=None, group_factors: list[list[str]]|None=None,
                   dataset_handle=None) -> str
```
- 値は `stats.preprocess.PREPROCESS_DEFAULTS` の各欄へ写す。`None` はその足切りを行わない（`filters.<name> = null`）。
- 戻り値: `{status:"success", matrix_id, n_units, n_qc, n_features_before, n_features, subject_source, quant:{normalized, method, unit},
  steps:[{step, status, reason?, 件数}]（一覧は切る）, warnings, record:{record_id, path} | {written:false, reason}, next}`。
  `needs_input` のときは下の封筒。
- 行列は `ds.stat_matrices[matrix_id]`（新しい欄）に `PreparedMatrix` と設定・指紋ごと保持する。v1 の `pp_*` には**書かない**。

### `dataset_compare`（新規）

```
dataset_compare(reference_group: str|None=None, test_group: str|None=None,
                groups: list[str]|None=None, comparisons: list[dict]|None=None,
                factors: list[str]|None=None, covariates: list[str]|None=None, block: str|None=None,
                matrix_id: str|None=None, method="moderated_t", effect_size="log2_mean_difference",
                bh_population="matrix", q_threshold=0.05, equivalence_fc=1.2, log2fc_threshold=1.0,
                allow_confounded=False, group_levels=None, group_factors=None, top_n=10,
                dataset_handle=None) -> str
```
- 群の指定はちょうど 1 つ: `reference_group`+`test_group`（2 群）／`groups`（3 群以上。先頭が基準で、各群 − 基準の対比と omnibus F）／
  `comparisons`（spec v2 の `comparisons` の形そのまま。2 因子・`at`・交互作用。`factors` が要る）。それ以外は `DATASET_BAD_REQUEST`。
- `covariates` は試料の表の列名。値がすべて数値なら `numeric`、さもなくば `categorical`。`block` は `"subject_id"` だけを受ける。
- `matrix_id` は `dataset_preprocess` が返した ID（その設定で前処理し直す）。省略時は既定の設定。古い・無い ID は
  `missing_state("stat_matrix", ["dataset_preprocess"])`。
- `log2fc_threshold` は図の色分け・`large_changes` の数え方・export の `significant` 列にだけ使い、判定には使わない（spec §7）。
- 組み立てた spec v2 を `run_spec_v2` で実行する（前処理は spec の中で 1 回）。`analyses` は `compare` 1 つ。
- 戻り値（要約だけ）: `{status, result_id, matrix_id, rule_hash, test, effect_size_definition:{name}, ci_level, verdict_rule,
  bh_population:{name, n_by_contrast, q_interpretation}, subject_source, group_n, prior:{s2_prior, df_prior}|null,
  contrasts:[{contrast_id, reference, test, n_tested, n_not_tested, verdicts:{changed, unchanged, inconclusive}, large_changes,
  presence:{available, n_q_below}}], omnibus:{n_tested, n_q_below}|null, top: TSV, confounding:{batch_table, warnings}, warnings,
  record, next}`。`top` は対比ごとに changed の上位 `top_n` 件（q の小さい順）の
  `contrast_id feature_id name log2fc ci_low ci_high q verdict`。全行は `ds.results[result_id]`。
- `result_id = "cmp_" + canonical_hash({rule_hash, matrix_id, log2fc_threshold})[:12]`（同じ呼び出しは同じ ID）。
  `ds.last_differential` も同じ記録を指す（既定の書き出し・図の対象）。

### `dataset_pca`（引数を入れ替える）

```
dataset_pca(matrix_id: str|None=None, scaling="autoscale", n_components=5, impute="half_min",
            group_levels=None, group_factors=None, dataset_handle=None) -> str
```
- `log_transform` は消す（エンジンは常に log2）。軸は生体の個体で決め、QC は投影する（`stats.pca.pca`）。
- 群（`group_levels` / `group_factors`、無ければ試料の表の `group`）は色分けの表示と結果の記録にだけ使い、PCA の数字には効かない。
- 戻り値: `{status, result_id, matrix_id, scaling, log2:true, imputation, n_fit, n_qc_projected, explained_variance_ratio,
  groups:{群: 個体数}, record, loadings_note}`。全量（スコア・ローディング）は `ds.results[result_id]` と `ds.last_pca`。

### `dataset_analysis_run`（振り分け）

- `spec["schema"] == "analysis-spec.v2"` → `normalize_spec_v2` → `run_spec_v2`。それ以外（欄なし・v1）→ 今の `analysis_spec`。
- v2 の要約は解析ごとに `{analysis_id, kind, n_rows, n_tested, verdicts, n_q_below}`（pca は `explained_variance_ratio`）。
  行の扱い（50 行まで TSV、超えたら `ANALYSIS_OUTPUT_REQUIRED`、`output_path` に JSON）は v1 と同じ規則。`needs_input` はそのまま封筒。
- 状態を変えない・記録を書かない（判断表 #9）。
- 組成（spec §11、`kind: "composition"`）は spec §14 に対話のツールが無いので、この段では `dataset_analysis_run` の v2 からだけ使える
  （A の概観が対話の入口を決める）。

### `needs_input` の封筒（`mcp_errors.needs_input`）

```
{"needs_input": {"field": "preprocess.drift.mode", "reason": "...", "options": [{"value", "label"}...],
                 "argument": "drift_mode", "retry_tools": ["dataset_preprocess", "dataset_compare", ...]}}
```
- `error` ではない（クライアントは利用者に尋ねてから `argument` に値を入れて呼び直す）。`missing_state` と並ぶ機械可読の封筒として
  `mcp_errors` のモジュール docstring・`docs/output_format/core.md`・`MCP_INSTRUCTIONS` に書く。
- `dataset_analysis_run` の v2 では `argument` の代わりに spec の `field`（`preprocess.drift.mode`）を示す。

### `pathway_project`

- 新しい引数 `matrix_id: str|None=None`（省略時は既定の前処理）。`missing_state("preprocessed_matrix", ...)` は無くなる。
- ノードの比較は `pathway.compare.compare_scopes` がエンジンの `compare`（`moderated_t`）を**スコープ種別ごとに 1 回**呼ぶ
  （BH はパスウェイ × スコープ種別ごと、今のまま）。`nodes.tsv` に `p` `ci_low` `ci_high` `verdict` を足す。
